# Community detection для улучшения товарных эмбеддингов

## Общая информация

- **Название:** Community detection для улучшения товарных эмбеддингов
- **Тип:** исследовательский
- **Вид:** индивидуальный

**Требования:** знание основ Deep Learning. Будет плюсом опыт обучения эмбеддингов и знание алгоритмов кластеризации.

## Аннотация

Каталог Яндекс Маркета насчитывает сотни миллионов товарных предложений. Одна из важных задач при работе с каталогом — матчинг товаров, то есть поиск предложений, относящихся к одному и тому же товару.

Для решения этой задачи применяются трансформерные модели. Они преобразуют текстовое описание товара в числовой вектор — эмбеддинг. Модель должна располагать одинаковые товары близко друг к другу, а разные товары — дальше. В результате каталог можно представить как большое пространство товарных эмбеддингов со своей внутренней структурой.

Основная гипотеза работы состоит в том, что информацию об этой структуре и найденных в ней сообществах можно использовать как дополнительный сигнал для улучшения эмбеддингов. Даже при отсутствии ручной разметки кластеры могут выступать в роли временных псевдометок для дальнейшего обучения модели.

## Цель

Улучшить качество эмбеддингов товаров с помощью структуры пространства эмбеддингов и методов поиска сообществ, чтобы в дальнейшем повысить точность матчинга одинаковых товаров.

## Задачи

1. Исследовать датасет, тексты товаров и исходное пространство эмбеддингов.
2. Подобрать и сравнить алгоритмы кластеризации и поиска сообществ.
3. Разработать подход к использованию кластеров как сигнала для дообучения эмбеддингов.
4. Выполнить несколько итераций обучения encoder по псевдометкам.
5. Сравнить исходные и дообученные эмбеддинги на внешней задаче.
6. Протестировать итоговый подход на валидационном датасете размеченных пар товаров.

## Планируемый результат

Алгоритм дообучения товарных эмбеддингов с использованием community detection и экспериментальная оценка его влияния на качество представлений.

## Данные

В работе используется датасет электроники Яндекс Маркета объёмом около 4,79 млн строк и 122 категорий. Для каждого товара доступны:

- идентификатор модели;
- идентификатор категории;
- текстовое описание;
- путь в каталоге;
- готовый эмбеддинг размерности 312.

Полный датасет и веса модели не хранятся в GitHub из-за их размера. Ноутбуки используют файлы из локальных каталогов `data/raw` и `models`.

## Применение DeepCluster

В качестве основного метода используется подход из статьи [Deep Clustering for Unsupervised Learning of Visual Features](https://arxiv.org/abs/1807.05520). Исходный алгоритм предложен для изображений, а в данной работе адаптирован для текстовых эмбеддингов товаров.

DeepCluster чередует два этапа:

1. Текущая версия BERT вычисляет эмбеддинги всех товаров обучающей выборки. Эмбеддинги проходят PCA, whitening и L2-нормализацию, после чего разбиваются на группы методом K-Means.
2. Номера кластеров используются как псевдометки. К encoder добавляется временная линейная голова, и модель обучается предсказывать кластер товара с помощью cross-entropy.

После прохода обучения эмбеддинги и кластеры вычисляются заново. Номера кластеров между итерациями могут менять смысл, поэтому классификационная голова каждый раз создаётся заново, а обученные веса BERT сохраняются.

Категории товаров не участвуют в формировании псевдометок и обновлении BERT. Они используются только для внешней оценки: на эмбеддингах train-части обучается KNN-классификатор, после чего измеряются Accuracy и Macro-F1 на отложенной validation-части.

Для снижения риска вырожденного решения контролируются размеры кластеров, разброс эмбеддингов и NMI между соседними разбиениями. При обучении применяется балансировка псевдоклассов: товары из небольших кластеров получают большую вероятность попадания в мини-батч.

## Основной эксперимент

Итоговый запуск выполнен со следующими параметрами:

- 20 000 товаров в train;
- 5 000 товаров в validation;
- 20 различных категорий;
- 1 000 обучающих и 250 проверочных товаров на категорию;
- 100 псевдокластеров;
- 3 итерации DeepCluster;
- batch size 32;
- 1 875 шагов оптимизатора;
- максимальная длина текста 128 токенов;
- CLS-эмбеддинги размерности 312;
- до 128 компонент PCA.

Дообучался encoder `rubert-tiny2`, ранее обученный на товарных данных. Основная часть эксперимента заняла около 11,4 минуты на Mac с использованием MPS.

## Результаты

| Состояние эмбеддингов | Accuracy KNN | Macro-F1 KNN |
|---|---:|---:|
| Исходный BERT, бейзлайн | 0,8550 | 0,8529 |
| После первой итерации | 0,8494 | 0,8468 |
| После второй итерации | 0,8488 | 0,8460 |
| После третьей итерации | 0,8390 | 0,8363 |

Кластерный loss при этом уверенно снижался:

| Итерация | Loss до обучения | Loss после обучения |
|---:|---:|---:|
| 1 | 4,7369 | 0,2579 |
| 2 | 4,7582 | 0,1902 |
| 3 | 4,7496 | 0,1237 |

Изменение весов последнего attention-слоя составило 0,314391 по L2-норме. Это подтверждает, что обновлялась сама модель BERT, а не только временная классификационная голова.

NMI между соседними разбиениями достиг 0,8650: по мере обучения кластеры становились стабильнее. При этом NMI кластеров с категориями изменился с 0,4615 до 0,4576.

## Выводы

Реализованный цикл соответствует основной идее DeepCluster: эмбеддинги кластеризуются, кластеры превращаются в псевдометки, BERT обучается на этих метках, после чего представления и разбиение пересчитываются.

Эксперимент подтверждает, что модель успешно учится предсказывать псевдокластеры: loss после обучения снижается на каждой итерации, параметры encoder заметно изменяются, а сами разбиения постепенно стабилизируются.

Однако качество категориальной классификации KNN относительно бейзлайна снизилось: Accuracy изменилась на −1,60 процентного пункта, Macro-F1 — на −1,66 процентного пункта. Следовательно, минимизация loss по псевдометкам сама по себе не гарантирует, что новые эмбеддинги станут лучше отражать категории товаров. Вероятно, модель усиливает структуру, найденную K-Means, но эта структура лишь частично совпадает с категориальной.

Ранее проведённый пилотный эксперимент на 2 000 товарах показывал улучшение Macro-F1, но эффект не подтвердился на выборке из 25 000 товаров. Это подчёркивает необходимость проверять методы обучения эмбеддингов на достаточно больших выборках и не делать вывод по одному небольшому сэмплу.

Текущий результат нельзя считать окончательной оценкой качества матчинга. KNN по категориям проверяет, сохраняют ли эмбеддинги категориальную информацию, но матчинг одинаковых товаров является более узкой задачей. Следующим этапом должна стать оценка на независимом датасете размеченных пар товаров с метриками ROC-AUC, PR-AUC, precision, recall и F1 при выбранном пороге близости.

Также имеет смысл исследовать меньшее число кластеров, меньший learning rate, замораживание нижних слоёв BERT, раннюю остановку и повторение эксперимента с несколькими случайными seed.
